DATASCI 207: Applied Machine Learning

Live Session Demos

Instructor materials: the notebooks walked in the live sessions, week by week, each with a line on what it is there to teach. Images and supporting files sit alongside each notebook in the repository, so the Colab links run as-is.

Week 1

  • Module 1 - Introduction_and_framing — Colab
    One dataset end to end: linear vs degree-4 vs degree-15 polynomial fits, so evaluation, generalization, and overfitting are seen by example before they are named.

Week 2

  • Module 2 - Linear_regression (gradient descent) — Colab
    Linear regression on the diabetes dataset: EDA, a one-variable baseline, and the gradient-descent training loop built up in the open.
  • Module 2 - Tensorflow_introduction — Colab
    First contact with TensorFlow/Keras: tensors and the basic build-compile-fit workflow, so the framework is familiar before it matters.

Week 3

  • Module 3 - Feature engineering — Colab
    The COVID growth-rate regression pipeline: creating, cleaning, and selecting features, defining train/test periods, and watching preprocessing choices move a linear model.

Week 4

  • Module 4 - Logistic_regression_binary — Colab
    Binary logistic regression on the wine data: the sigmoid, a two-feature decision boundary you can draw, and a breakout-room exercise.

Week 5

  • Demo_async — Colab
    Iris softmax regression from scratch: sparse vs dense labels, softmax normalization, cross-entropy, the gradient, and then the same model in Keras.
  • Module 5 - Logistic_regression_multiclass — Colab
    Multiclass logistic regression on the wine data: from two classes to k, with EDA and per-class evaluation.

Week 6

  • Module 6 - FFNN — Colab
    A feedforward network on the APTOS retina images: class imbalance, augmentation, and a look at what each layer has learned.

Week 7

  • KNN / Module 7 - KNN_classifier — Colab
    KNN together with the preprocessing it quietly depends on: ordinal vs nominal encoding and feature scaling, then the classifier itself.
  • decision_trees / Module 7 - Decision_trees — Colab
    Entropy and information gain computed by hand on binarized features, so the tree’s choice of splits stops being magic.
  • ensembles / Module 7 - Ensemble_learning — Colab
    Why many weak models beat one: the majority-vote principle, bagging, and AdaBoost, tuned with cross-validation.

Week 8

  • Clustering / Module 8 - Clustering_analysis_part1 — Colab
    K-means implemented from scratch, the elbow and silhouette diagnostics for choosing k, then agglomerative and density-based (DBSCAN) clustering.
  • Clustering / Module 8 - Clustering_analysis_part2 — Colab
    Gaussian mixtures vs k-means: the 1-D expectation-maximization walkthrough, estimating means, spreads, and weights step by step.
  • PCA / Module 8 - PCA — Colab
    PCA built by hand — standardize, covariance matrix, eigendecomposition, projection — ending with image reconstruction on the pet photos.

Week 9

  • Module 9 - Embeddings for text — Colab
    Sentiment on the drug-review corpus with a learned Embedding layer, then inspecting the geometry the embeddings picked up.

Week 10

  • Module 10 - CNNs — Colab
    Convolutions applied to text: a CNN over the drug-review sequences, with embedding inspection and evaluation — the same mechanism as images, different axis.

Week 12

  • Breakout_room_exercise — Colab
    The fairness breakout on the Adult census data: predict income bracket, then evaluate it with sub-group confusion matrices through the FairAware tasks.

Week 13

  • Module 13 - Sentiment_Bert_PubMedEmbeddings_(feature_based_approach) — Colab
    PubMedBERT as a frozen feature extractor for drug-review sentiment: transfer learning without touching the pre-trained weights, against a dummy baseline, with a SHAP explainability teaser.
  • Module 13 - Sentiment_Bert_PubMedEmbeddings_(fine_tuning_approach) — Colab
    The same sentiment task, fine-tuning BERT end to end — the comparison partner to the feature-based notebook: what updating the pre-trained weights buys.
