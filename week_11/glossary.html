Module 11 Glossary

Functional API
The Keras style in which layers are functions called on tensors and a model is whatever graph runs from its inputs to its outputs. Branches, merges, multiple inputs, and multiple heads are all expressed the same way; the Sequential stack is the special case.
Sequential API
The stack-shaped special case: one input, layers in a line, one output. Enough for every model in this course before this module.
Named Input
A keras.Input with a name. With several inputs, data is fed as a dict keyed by these names — the names are the contract between the data pipeline and the model.
Concatenate
The merge layer that joins the per-feature paths into one flat vector, feeding the shared trunk. The width of that vector drives the trunk’s parameter count.
Discretization (Bucketing)
A layer that maps a number into one of a few ranges and emits a one-hot of the range. Zero trainable parameters; used when a feature’s effect is not smooth, so each range can earn its own learned effect.
One-Hot Encoding
A category as an indicator vector: all zeros except one slot. Costs width but no parameters. Keras lookup layers reserve an extra out-of-vocabulary slot, so widths run one wider than the raw category count.
StringLookup / IntegerLookup
Layers that map raw category values (strings or integers) to indices or one-hot vectors against a fixed vocabulary, with a reserved slot for values never seen in training.
Embedding Layer (tabular)
A learned vector per category — vocabulary size × dimension parameters. Buys geometry: categories the task treats alike can drift together. The only encoding that scales to thousands of categories.
Multi-Output Model
One trunk, several heads, each predicting its own target with its own loss. Training minimizes a weighted sum of the per-head losses jointly.
Loss Weights
The coefficients on each head’s loss in the joint sum. They set the exchange rate between objectives that share one trunk.
Baseline (rule-based)
The bar to clear before wiring anything: the majority class, then one honest rule. A network that cannot beat one rule is decoration.
plot_model
The Keras utility that draws the graph you wired, shapes included. For a Functional model, the drawing is the design document.
Regularization (the tuning thread)
Not a lecture week in this course — it runs as a practice thread through the assignments: learning curves, grid and random search, early stopping, keras-tuner. See the tuning-thread figure in this module’s Go deeper section.
